Selected Projects

Multi-Radio Coexistence Test Automation Framework

Manually running coexistence sweeps in the field is slow and hard to repeat exactly the same way twice. I built a Python framework to script those same tests on the bench — cellular, Wi-Fi, BT, GNSS, and NFC — so I could run the exact same sequence over and over and actually trust the comparison between runs. The trickier part was building logic to tell the difference between a real RF issue (timing, power, desense) and something that just looked like one but was actually a device bug — that distinction alone saved a lot of back-and-forth with firmware teams.

Python, VSA/Spectrum Analyzer control, custom test-sequencer

RF Characterization & KPI Benchmarking Toolkit

This started as a way to stop re-running the same bench measurements by hand — sensitivity, TX power, EVM, spurious emissions — every time a new firmware build came in. I scripted the sweeps so results get pulled straight off the VNA/signal generator/spectrum analyzer and checked automatically against 3GPP and operator thresholds. Later I extended it to also log field KPIs like RSRP, SINR, BLER, and throughput over time, so I could spot a regression between builds just by looking at a trend line instead of digging through raw numbers.

Python, MATLAB, Keysight/R&S instrument drivers

Cross-Layer Log Correlator for Handover & Recovery Debug

Debugging a handover or recovery failure usually means scrolling through a QXDM log layer by layer — PHY, MAC, RLC, PDCP, RRC — trying to line up timestamps in your head. I got tired of doing that manually, so I wrote a parser that ingests the log and lines events up against the connectivity event itself (say, a Wi-Fi-to-cellular handover or an out-of-service recovery), so I can see exactly where in the stack the delay or failure actually started instead of guessing.

Python, QXDM/QCAT log parsing, pandas
